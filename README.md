# Richmond Carpentry Services

Single-page website for Richmond Carpentry Services, Portishead, North Somerset.
Live at https://richmondcarpentryservices.co.uk, deployed on Cloudflare Pages from `main`.

Built with Vite, React, TypeScript and Tailwind.

```sh
npm install
npm run dev     # local dev server on http://localhost:8080
npm run build   # production build into dist/
```
